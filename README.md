# 복리후생 증빙 검수

학자금 신청을 예로 규정 등록부터 HR의 최종 결정까지 연결하기 위한 개인 공개 저장소입니다. 첫 버전에는 폴더별 책임과 협업 규칙이 담겨 있습니다. 실행 가능한 서비스는 아직 포함하지 않았습니다.

## 목표 흐름

규정 관리자가 검수 기준을 게시합니다. 신청자가 금액과 증빙을 제출하면 OCR이 문서를 읽고 개인정보를 가립니다. 검수 엔진은 게시된 규정에 따라 항목을 분류하고 금액을 계산합니다. HR 담당자는 근거와 결과를 확인해 최종 결정을 기록합니다.

## 개발 시작

| 작업 | 위치 |
| --- | --- |
| 신청자와 HR 및 규정 관리자 화면 | [frontend](frontend/) |
| 신청 접수와 규정 게시 및 검수 | [backend](backend/) |
| 문서 판독과 마스킹 | [ocr](ocr/) |
| 모듈 간 데이터 형식 | [contracts](contracts/) |
| 가상 신청의 전체 흐름 검증 | [tests/integration](tests/integration/) |

첫 구현 목표는 새로 복제한 환경에서 가상 신청 한 건의 검수 결과를 여는 것입니다. 작업을 시작하기 전에 [협업 규칙](CONTRIBUTING.md)을 읽어 주세요.
